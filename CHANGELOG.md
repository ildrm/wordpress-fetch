# Changelog

## 1.0.0 — 2026-09-17

- Added RSS 2.0, RDF, Atom, Media RSS, enclosure, and OPML parsing.
- Added safe remote transport, XXE rejection, HTML sanitization, encrypted credentials, and media validation.
- Added custom-table sources, profiles, groups, durable jobs, import identities, and structured logs.
- Added rules, templates, dynamic destination discovery, deduplication, selective updates, and editorial locks.
- Added explicit canonical/robots policy, supported SEO-provider delegation, sitemap filtering, Open Graph, and Article schema.
- Added an accessible responsive admin wizard, dashboard, source list, activity, OPML tools, REST API, WP-CLI, and source attribution block.
